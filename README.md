# AI-Based-Resume-Analyzer-Job-Role-Prediction-System

🚀 Project Overview

This project is an AI-powered Resume Analyzer that uses Machine Learning and Natural Language Processing to analyze resumes, extract skills, predict suitable job roles, identify missing skills, and generate a skill match percentage. It also supports PDF resume upload, stores analysis history, and generates downloadable reports.

🎯 Key Features
📌 Resume text & PDF upload support
🤖 AI-based job role prediction using Naive Bayes ML model
🧠 Skill extraction from resumes using NLP techniques
📊 Skill match percentage calculation
❌ Missing skill identification
💾 SQLite database integration for storing history
📄 PDF report generation using ReportLab
🌐 Multi-page Flask web application (Dashboard, Roles, Settings, History)
